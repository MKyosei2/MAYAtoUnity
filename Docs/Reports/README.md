# Generated Validation Reports

This directory is the standard location for portfolio validation artifacts generated by CI or local dry-runs.

Expected generated files:

```text
portfolio_validation_report.md
portfolio_validation_report.json
maya_sample_manifest.json
```

The validation harness is intentionally dry-run by default. It does not modify Unity scenes, prefabs, meshes, or imported assets. Errors are written into the Markdown/JSON report before the script exits with a non-zero code, so CI failures remain inspectable.

Local command:

```bash
python scripts/portfolio_validation.py --dry-run --report-dir Docs/Reports
```

For full Unity validation, open the project in Unity and run:

```text
Tools/MAYAtoUnity/Validate All Samples
```
