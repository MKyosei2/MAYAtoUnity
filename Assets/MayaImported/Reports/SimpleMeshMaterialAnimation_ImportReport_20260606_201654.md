## 11. Interpretation

This report separates **source discovery** from **Unity behavior parity**.

- A node listed in this report means the importer discovered and preserved source evidence for it.
- A reconstructed Unity object means the builder created an inspectable GameObject/component representation.
- JSON Bridge counts prove that bridge data was parsed and represented in `MayaSceneData`; visual or runtime parity still requires Unity scene inspection.
- Full Maya runtime behavior, shader parity, rig evaluation, deformer evaluation, and plugin-specific behavior require explicit validation per sample scene.
